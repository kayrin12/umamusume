赛马娘助手 v0.4 · Windows 10/11 64位便携版

不需要自行安装 Python、Node.js 或管理员权限。
完整包约22MB；已有v0.3可下载小型升级包，节省空间。

升级：先“退出助手”，把升级包顶层umacoach文件夹与旧版同名文件夹合并，覆盖同名文件。
保留旧版.runtime和local-data；在原目录运行start.bat，页面应显示“v0.4 整局状态记录”。
不要把升级包解压到新目录独立运行；已安装的Codex组件可复用，无需重新下载。

首次安装：完整解压便携包，进入umacoach文件夹，双击start.bat。
不要在ZIP内直接运行，不要打开panel.html，也不要在聊天预览里读取窗口。
浏览器未自动打开时，复制启动窗口显示的本机面板地址。

1. 选择游戏窗口并“应用配置”。找不到时可用3秒后选择前台窗口或手动框选。
2. 默认ChatGPT账号模式：点击“使用 ChatGPT 登录”，完成官方登录，再“检查登录状态”。
   首次下载约162MB官方Codex组件，解压约449MB；后续复用。
   使用账号Codex额度和限额，不是无限免费使用。API模式另行计费，不会自动切换。
3. 先“立即读取 / 分析”，确认正常后再持续读取。中途接入和重启后先确认局次。
4. v0.4新增“查看 / 修正本局状态”：导师、心得与替换、三色指南条、外出、亲友、
   体力干劲、比赛和Dream Fest记录。空白表示未知，0表示确认是0。
   打开修正会暂停读取；保存后重新分析或恢复读取。新局状态清空，旧局记录保留。
5. 看不清、低置信度不会覆盖已确认状态；旧值可能过时，漏读请打开对应页面或手动修正。
6. 使用完点击“退出助手”。仅关闭网页不会退出后台。
