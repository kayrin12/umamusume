赛马娘助手 v0.6 · Windows 10/11 64位便携版

不需要自行安装 Python、Node.js 或管理员权限。
完整包约22MB；已有v0.3/v0.4/v0.5可下载小型升级包，节省空间。

升级：先“退出助手”，把升级包顶层umacoach文件夹与旧版同名文件夹合并，覆盖同名文件。
保留旧版.runtime和local-data；在原目录运行start.bat，页面应显示“v0.6 自采模板快速识别”。
不要把升级包解压到新目录独立运行；已安装的Codex组件可复用，无需重新下载。

首次安装：完整解压便携包，进入umacoach文件夹，双击start.bat。
不要在ZIP内直接运行，不要打开panel.html，也不要在聊天预览里读取窗口。
浏览器未自动打开时，复制启动窗口显示的本机面板地址。

1. 选择游戏窗口后直接点读取，自动应用配置。找不到时可用3秒后选择前台窗口或手动框选。
2. v0.6先用自采模板快速识别：确认局次后固定角色，按文末说明采样并开启持续读取。
   兼容文字OCR仍可选：校准日期、完整训练收益和训练名称区域，切换预览即可比较。
   系统需中文/日文OCR组件；没有时会提示，可快速录入。未在真实Windows验收OCR准确率。
   日期/剩余回合分开显示，实际第N回合需在已知日期标定。体力条/友情等图形不猜精确值。
   模型用于事件/心得等不规则画面。默认ChatGPT账号模式：点击“使用 ChatGPT 登录”，完成官方登录，再“检查登录状态”。
   首次下载约162MB官方Codex组件，解压约449MB；后续复用。
   使用账号Codex额度和限额，不是无限免费使用。API模式另行计费，不会自动切换。
3. 先“立即读取 / 分析”，确认正常后再持续读取。中途接入和重启后先确认局次。
4. v0.4新增“查看 / 修正本局状态”：导师、心得与替换、三色指南条、外出、亲友、
   体力干劲、比赛和Dream Fest记录。空白表示未知，0表示确认是0。
   打开修正会暂停读取；保存后重新分析或恢复读取。新局状态清空，旧局记录保留。
5. 看不清、低置信度不会覆盖已确认状态；旧值可能过时，漏读请打开对应页面或手动修正。
6. 使用完点击“退出助手”。仅关闭网页不会退出后台。

v0.6自采模板：
- 先“采集样本”，从自己的客户端采0–9和+，再设置完整数值选区。
- 无收益若显示空白，选择“已确认空白零收益”，亲自确认后填0；每个字段分别采。
- 五个选中训练图案都采一次。头像含空槽empty，彩圈/羁绊/!用yes/no；未知不会按0算。
- 体力/指南条用自己的填充与背景颜色校准。读错时可修正本帧，画面变了修正自动失效。
- 选“自采模板快速识别”，开持续读取，自己切训练即可自动排序；训练不经过模型。
- 日期可走独立后台OCR，也可采学年/月/前后半组件；实际第N回合需要可靠起点标定。
- 目标采样10帧/秒，仅重匹配变化字段。300ms是目标，不是实机保证，面板显示实际耗时。
- 模板保存在local-data/templates，不用第三方素材，不附带大型识别模型。
- 权重可在“评分权重配置”编辑，存local-data/training_weights.json。仍不保证最优或达到UB。
- Windows及真实游戏识别仍待验收。没有读到的头像、数字、状态或门槛一律保留未知。
