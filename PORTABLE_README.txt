赛马娘助手 · Windows 64位便携版

使用这个包不需要安装 Python，不需要管理员权限。

1. 把整个 ZIP 解压到一个可写目录，例如桌面的“赛马娘助手”。
2. 进入解压后的 umacoach 文件夹，双击 start.bat。
   请勿直接在压缩包中双击，必须先全部解压，也不要只复制 start.bat。
   不要打开 panel.html，不要在聊天预览中使用助手，预览无法访问你电脑的窗口。
3. 程序自动打开浏览器中的本机面板，保留启动时出现的命令窗口。
   如果未自动打开，将命令窗口显示的“本机面板地址”复制到浏览器。
4. 打开游戏，点击“刷新窗口”，选择游戏窗口并点“应用配置”。
5. 点击“开始持续读取”。不填 API 密钥也能预览游戏画面。
6. 要用现有ChatGPT账号获取建议，点击“使用 ChatGPT 登录”。
   首次自动下载约162MB官方Codex组件（解压约449MB），之后复用，不需要Python或Node.js。
   在官方页面完成登录，回到助手点击“检查登录状态”，然后“立即读取 / 分析”。
   使用的是账号Codex额度和限额，取决于套餐及官方服务，不是无限免费使用。
   也可以自行切换API模式，填写API密钥，API单独计费。不会自动从账号模式切换API计费。
7. 中途放弃重开会尝试识别；归属不确定时会暂停建议，请用“记录为新局”确认。
8. 结束使用时点击“退出助手”或关闭命令窗口。仅关闭网页不会退出后台。

列表里没有游戏（v0.2新增）：
- 点“3秒后选择前台窗口”，立即切回游戏并等3秒，再回来查看预览。
- 或点“手动框选游戏画面”，在桌面预览上拖出游戏区域，确认后开始持续读取。
  桌面截图只在本机用于选区，后续只读取选定区域。游戏移动或缩放后请重新框选。
- 若仍失败，点“查看读取诊断”获取版本、窗口数量等排查信息；其中不含密钥和截图。
- 更新时先退出旧助手，重新解压运行，页面顶部应显示“v0.3 ChatGPT 账号模式”。

若出现 Unexpected token 或 XML：请先确认运行的是本机 start.bat 自动打开的页面。
新版会在连接检查通过前停用操作，并对非助手内容显示可读提示；不会修改系统代理设置。

便携包包含 Python Software Foundation 官方 NuGet 运行环境与 Pillow 官方 Windows 依赖，
启动不需要联网下载这些组件，也不会修改系统 PATH 或安装全局 Python。
截图只在账号登录/配置API后触发分析时发送到选用的模型服务。不录像。
Codex模式会临时保存待分析截图，结束后删除，强制退出可能残留，可退出后清理local-data/codex-tmp。
ChatGPT登录由官方Codex管理，程序不读取或复制登录令牌，不要把登录凭据发到聊天。
请让游戏窗口可见、不要最小化或被助手页面遮住。

当前是原型，未在真实 Windows 游戏客户端验收。攻略仍在核验，不能保证每回合最优或达到 UB。
仅支持64位 Windows 10/11；需要真实 Windows 实测启动、屏幕捕获和视觉模型效果。
本地局次及识别文字保存在 local-data 中，退出后可以删除。
若遇到错误，请保留命令窗口的报错文字，发送时不要包含 API 密钥。
