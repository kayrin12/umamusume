# Windows 便携版下载

- [v0.7.0 完整包（约22MB）](umacoach-windows-portable-x64-v0.7.0.zip)
- [v0.3 / v0.4 / v0.5 / v0.6 → v0.7.0 小型升级包](umacoach-upgrade-to-v0.7.0.zip)

已有v0.3–v0.6：先退出助手，将升级包顶层umacoach文件夹与旧版顶层同名文件夹合并，覆盖同名文件；保留原.runtime和local-data，在原目录运行start.bat。可复用已安装的Codex，避免重复占用空间。

首次安装：完整解压完整包，进入umacoach文件夹双击start.bat，无需系统Python。不要直接打开panel.html或使用聊天预览。

v0.7默认自动定位与变化区域OCR，选窗口后点“开始自动辅助”即可，不需采集模板、框选字段或登录模型。高级手工工具仍可选用。首次定位可能慢，真实Windows识别与速度尚未验收。

训练建议只在本机计算。事件/心得AI可选，ChatGPT模式用官方Codex额度；首次使用该模式下载约162MB组件（解压约449MB），本地训练不需它。API模式另行计费。

只读、不点击、不读内存、不抓包。攻略为跨服推定，赛程/粉丝门槛仍不完整，不保证最优或达到UB。

每个ZIP有对应.sha256；旧版保留供兼容。完整说明见仓库README。
